# Project Context Has Moved

This compatibility entry is no longer a maintained context template. Durable organization, product, project, marketing, brand, website, technical, decision, and change context is owned by [Contextus](https://github.com/kostja94/contextus).

Create root `contextus.md` with Contextus instead:

```bash
npx skills add kostja94/contextus --skill contextus
```

Marketing Skills remains usable without Contextus. Give the agent sufficient project material or facts in the conversation; it will ask for missing information and complete the marketing task without creating a parallel context system.

Existing legacy `project-context.md` files may still be read as fallback material, but this repository no longer defines or updates their format.
